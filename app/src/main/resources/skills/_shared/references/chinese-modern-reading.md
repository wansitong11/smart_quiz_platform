# 现代文阅读

## 一、信息类文本（论述类 / 实用类）

### 高频能力
- 理解重要概念的含义、重要句子的含意。
- 筛选整合信息，辨识常见设错：偷换概念、以偏概全、强加因果、无中生有、混淆已然未然、张冠李戴、答非所问。
- 分析论点、论据与论证方法（举例、引用、对比、类比、比喻论证），梳理论证思路。
- 归纳内容要点，概括中心意思，分析作者的观点态度。

### 题型与答题要点
- **内容理解**：定位原文区间 -> 逐项比对选项表述 -> 判定设错类型并说明理由。
- **论证分析**：先指明论证方法，再说明"论证了什么观点"，不能只答方法名称。
- **思路梳理**：按"首先—然后—最后"分层概括，层意必须落在原文关键词上。
- **观点探究**：亮明观点 -> 引原文依据 -> 联系材料外事例 -> 收束。

## 二、文学类文本（小说 / 散文）

### 小说
- 三要素：人物、情节、环境；核心落点是人物形象与主题。
- **人物形象**：先概括性格特征（形容词 + 具体表现），再以描写手法佐证（肖像、语言、动作、心理、细节、侧面烘托）。
- **情节作用**：从人物、情节、环境、主题、读者感受五个角度作答。
- **环境描写**：交代背景、渲染气氛、烘托心情、推动情节、暗示主题。
- **标题作用**：线索、概括情节、点明主题、塑造形象、艺术效果（双关、象征、悬念）。
- **叙述艺术**：叙述视角（第一/第三人称、有限/全知）、叙述顺序（顺叙、倒叙、插叙、补叙）、叙述节奏与留白。

### 散文
- **线索**：时间、空间、情感、事物；把握"形散神聚"的"神"。
- **语言鉴赏**：从用词、句式、修辞、节奏、语体风格入手，先指出手法，再说表达效果与情感。
- **情感意蕴**：由表及里，注意"表层含义—深层含义"双层结构。

## 三、通用答题规范
- 分点作答，先概括后分析，遵循"手法 + 内容 + 效果/情感"三段式。
- 术语必须与文本对应，禁止只罗列术语。
- 分值决定点数：约 1 分对应 1 个采分点，4 分题写 2～3 点并适度展开。
- 探究题允许开放，但必须"观点 + 文本依据 + 分析"三要素齐全。
