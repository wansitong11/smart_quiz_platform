# 写作

## 一、评分框架

### 基础等级（40 分）
- **内容（20 分）**：切合题意、中心突出、内容充实、思想健康、感情真挚。
- **表达（20 分）**：符合文体要求、结构完整、语言通顺、字迹工整。

### 发展等级（20 分）
- 深刻：透过现象深入本质，揭示问题产生的原因，观点具有启发性。
- 丰富：材料丰富、论据充实、形象丰满、意境深远。
- 有文采：用词贴切、句式灵活、善用修辞、文句有表现力。
- 有创意：见解新颖、材料新鲜、构思新巧、推理想象独到。

### 分档判定要点
- 一类卷：立意准确且有深度，结构严谨，语言有表现力。
- 二类卷：立意正确，结构完整，语言通顺。
- 三类卷：立意基本符合，结构松散或语言平淡。
- 四类卷：偏离题意、文体不符、字数严重不足。

## 二、审题与立意
- **材料作文**：抓关键词句 -> 分析材料层次与情感倾向 -> 提炼核心概念 -> 转换为可论证的观点。
- **任务驱动**：逐条划出任务指令（身份、对象、场合、文体、字数），漏掉任一任务即降档。
- **立意区间**：区分"最切题—切题—基本符合—偏离"，立意越靠近材料核心越安全。
- 常见失误：只截取材料一句话发挥、把材料当论据而丢掉材料指向、套作与宿构。

## 三、结构与论证
- **议论文基本框架**：引论（引出观点）-> 本论（并列式 / 递进式 / 对照式）-> 结论（升华呼告）。
- **分论点设置**：并列分论点要"同一维度、互不交叉"；递进分论点按"是什么—为什么—怎么办"展开。
- **段落范式**：观点句 -> 材料句 -> 分析句 -> 结论句。分析句是得分关键，不能只摆事例。
- **论证方法**：举例、引用、对比、类比、因果、归谬、辩证分析。
- **开头结尾**：开头 3～5 行内亮明观点；结尾回扣观点并适度升华，不空喊口号。

## 四、文体规范

### 议论文
观点鲜明，论据典型，分析到位，避免"以叙代议"。

### 记叙文
要素明确，细节生动，情感真挚，避免流水账。

### 书信 / 演讲稿 / 倡议书 / 评论
- 书信：称呼、问候、正文、祝语、署名、日期齐全；语气贴合对象与场合。
- 演讲稿：开头有呼告，中间有互动感（设问、排比），结尾有号召。
- 倡议书：标题、称呼、背景与缘由、具体倡议条目、落款。

## 五、素材与语言
- 素材分类积累：家国情怀、科技创新、文化传承、青年担当、生态环保、工匠精神、理性思辨。
- 素材运用：一材多用，通过不同分析角度支撑不同观点；避免"素材堆砌无分析"。
- 语言提升：善用短句与整散结合；恰当引用诗文提升文采；慎用生僻词与网络流行语。
- 卷面：标题居中、段落分明（建议 6～8 段）、避免大段涂改。
