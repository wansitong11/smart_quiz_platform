# 概率与统计

## 一、计数原理
- 分类加法计数原理与分步乘法计数原理。
- 排列数 A(n, m) = n!/(n − m)!，组合数 C(n, m) = n!/(m!(n − m)!)。
- 组合数性质：C(n, m) = C(n, n − m)；C(n, m) + C(n, m−1) = C(n+1, m)。
- 二项式定理：(a + b)^n 展开式，通项 T₍ᵣ₊₁₎ = C(n, r)a^(n−r)b^r。
  - 求特定项、系数最大项、二项式系数和（令 x = 1）。
- 常见方法：捆绑法、插空法、隔板法、间接法（总数减去对立面）。

## 二、概率
- 古典概型：P(A) = A 包含的基本事件数 / 基本事件总数。
- 互斥事件：P(A ∪ B) = P(A) + P(B)。
- 对立事件：P(Ā) = 1 − P(A)。
- 相互独立事件：P(AB) = P(A)P(B)。
- 条件概率：P(B|A) = P(AB)/P(A)。
- 全概率与贝叶斯公式（新高考重点，注意样本空间的完备划分）。
- 独立重复试验与二项分布：P(X = k) = C(n, k)p^k(1 − p)^(n−k)。

## 三、随机变量及其分布
- 离散型随机变量的分布列性质：pᵢ ≥ 0，Σpᵢ = 1。
- 期望：E(X) = Σxᵢpᵢ；性质 E(aX + b) = aE(X) + b。
- 方差：D(X) = Σ(xᵢ − E(X))²pᵢ = E(X²) − (E(X))²；性质 D(aX + b) = a²D(X)。
- 二项分布 X ~ B(n, p)：E(X) = np，D(X) = np(1 − p)。
- 超几何分布：不放回抽样，P(X = k) = C(M, k)C(N − M, n − k)/C(N, n)。
- 正态分布：图象关于 x = μ 对称，P(μ − σ < X < μ + σ) ≈ 0.6827，2σ 约 0.9545，3σ 约 0.9973。
- **易错**：分布列未验证概率和为 1；把"至少""至多"直接当独立事件。

## 四、统计
- 抽样方法：简单随机抽样、分层抽样（按比例分配）、系统抽样。
- 频率分布直方图：纵轴是频率/组距，面积为频率，所有矩形面积和为 1。
- 数字特征：平均数、中位数、众数、极差、方差、标准差；中位数需先排序。
- 百分位数计算：按位置 i = n·p% 判定取相邻两数的平均值还是该位置数。
- 线性回归：最小二乘法求 b̂、â，回归直线必过样本中心点（x̄, ȳ）。
  - 相关系数 r > 0 正相关，r < 0 负相关，|r| 越接近 1 线性相关性越强。
- 独立性检验：列联表与 χ² 统计量，判断两个分类变量是否有关联。
- **易错**：直方图纵轴误读为频率；回归方程预测超出样本范围时的外推风险。
