# 试卷概览（只读预览）设计稿

## 用例（先看这个）

1. 用户进入「试卷管理」，点开一份已切题完成的试卷。
2. 在试卷详情页顶部点「试卷概览」标签。
3. 页面按「大题 / 小节 / 材料 / 题目」把整份卷子的题干、选项、分值展示出来。
4. 用户只能折叠展开看内容，不能选答案、不能输入、不能交卷；看不到参考答案、解析、考点。

## 正文

### 目的

让用户在开始作答前，能先看清一份试卷大概考什么、有几道题、每道题多少分；同时预览必须只读，不能误改作答，也不能提前泄露答案。

### 触发

用户在「试卷管理」点开某份试卷，并切换到「试卷概览」标签时触发。

### 规则与步骤

1. **入口**：试卷详情页顶部在现有「试卷 / 识别审核 / 答题记录」之外，新增「试卷概览」标签；标签始终显示，方便用户知道有这个能力。
2. **数据获取**：打开标签时才请求一个新增的只读接口，后端从已缓存的切题结构重建出整卷结构；这个过程不创建练习会话、不调用大模型、不产生任何批改或作答副作用。
3. **只读展示**：前端直接复用已有的试卷结构组件，把「禁用作答」开关打开，并传入一份空答案；组件内的所有选项、填空、文本输入都会被禁用，只保留折叠/展开作为阅读辅助。
4. **隐藏答案**：后端返回前，把每道题的参考答案、评分要点、评分标准、解析、考点摘要、图形答案摘要和历史作答痕迹全部清掉，只保留题干、选项、材料正文和分值。

### 结果

用户看到一份和「开始作答」结构一致、但完全不能作答的试卷预览；每次打开都按当前切题结果实时生成，内容与最新试卷一致。

### 边界与异常

- 试卷未完成识别、等待校对、切题失败或正在切题时，不请求预览接口，直接显示「切题完成后可预览」占位提示。
- 用户没有该试卷访问权限、或试卷不存在时，接口返回 404，前端显示加载失败占位。
- 概览只接受已持久化的结构缓存；缓存缺失时返回「试卷结构缓存缺失，请重新切题后再查看」，不会为了预览触发模型调用。
- 整卷没有题目时，返回空结构，前端显示「暂无题目」。

### 可改点

- 想调整「预览是否允许折叠展开」，改前端只读组件的折叠行为即可。
- 想调整预览入口文案或位置，改详情页标签定义。
- 想改变「隐藏哪些字段」，改后端返回前的字段剥离规则。

## 附录（零猜测实现）

### A1 后端

**新增 DTO**

- 路径：`app/src/main/java/interview/guide/modules/resume/model/PaperOverviewDTO.java`
- 内容（record）：

```java
package interview.guide.modules.resume.model;

import interview.guide.modules.interview.model.PaperTree;

public record PaperOverviewDTO(
    Long paperId,
    String subjectId,
    int totalScore,
    int questionCount,
    PaperTree paperTree
) {}
```

**新增 Service**

- 路径：`app/src/main/java/interview/guide/modules/resume/service/PaperOverviewService.java`
- 依赖：`ResumePersistenceService`（按归属查找试卷）、`PaperStructureService`（重建结构）。
- 方法签名与逻辑：

```java
public PaperOverviewDTO overview(Long paperId) {
    PracticePaperEntity paper = resumePersistenceService.findById(paperId)
        .orElseThrow(() -> new BusinessException(ErrorCode.NOT_FOUND, "试卷不存在或无权访问"));
    if (paper.getRecognitionStatus() != null
        && paper.getRecognitionStatus() != RecognitionStatus.NONE
        && paper.getRecognitionStatus() != RecognitionStatus.READY) {
        throw new BusinessException(ErrorCode.BAD_REQUEST, "试卷仍在识别或等待校对，暂不可预览");
    }
    if (paper.getAnalysisStatus() != AsyncTaskStatus.COMPLETED) {
        throw new BusinessException(ErrorCode.BAD_REQUEST, "试卷切题完成后才能预览");
    }
    PaperStructureService.BuiltStructure built = structureService.buildCached(paperId);
    PaperTree studentTree = built.paperTree().forOverviewView();
    return new PaperOverviewDTO(
        paperId, built.subjectId(), built.totalScore(),
        studentTree.flattenQuestions().size(), studentTree);
}
```

- `PaperTree.forOverviewView()` 会递归把树中每道题的 `referenceAnswer`、`keyPoints`、`scoringRubric`、`analysis`、`topicSummary`、`visualContext`、`userAnswer`、`score`、`feedback` 清空，只保留题干、选项、材料和分值。
- `structureService.buildCached(paperId)` 只读取已持久化的结构快照；缓存缺失时抛业务异常，不调用模型。

**修改 Controller**

- 路径：`app/src/main/java/interview/guide/modules/resume/ResumeController.java`
- 新增字段 `private final PaperOverviewService overviewService;`
- 新增接口：

```java
@GetMapping("/api/resumes/{id}/overview")
public Result<PaperOverviewDTO> getOverview(@PathVariable Long id) {
    return Result.success(overviewService.overview(id));
}
```

### A2 前端

**API 与类型**

- 路径：`frontend/src/api/history.ts`
- 新增接口类型（文件已导入 `PaperTree`）：

```ts
export interface PaperOverview {
  paperId: number;
  subjectId?: string | null;
  totalScore: number;
  questionCount: number;
  paperTree: PaperTree;
}
```

- `historyApi` 新增方法：

```ts
async getPaperOverview(id: number): Promise<PaperOverview> {
  return request.get<PaperOverview>(`/api/resumes/${id}/overview`);
}
```

**新增只读预览组件**

- 路径：`frontend/src/components/paper-analysis/PaperOverviewPanel.tsx`
- 入参：`{ paperId: number }`
- 行为：挂载时调用 `historyApi.getPaperOverview(paperId)`；加载中显示加载态；失败显示占位与错误文案；成功后渲染头部（题数、总分）和 `PaperTreeView`。
- 关键渲染：

```tsx
<PaperTreeView
  tree={data.paperTree}
  answers={{}}
  disabled
  paperId={data.paperId}
  onAnswerChange={() => {}}
/>
```

- `disabled` 会传递到 `QuestionAnswerInput`，所有选项/输入禁用；折叠/展开仍可用。

**页面接线**

- 路径：`frontend/src/pages/ResumeDetailPage.tsx`
- `TabType` 联合类型增加 `'overview'`。
- `tabs` 数组在「试卷」后新增一项：`{ id: 'overview', label: '试卷概览', icon: BookOpen }`（从 `lucide-react` 导入 `BookOpen`）。
- `handleTabChange` 的 `order` 数组加入 `'overview'`。
- 内容区新增分支：
  - 当 `activeTab === 'overview'` 且 `resume.analysisStatus === 'COMPLETED'` 且 `resume.recognitionStatus` 为 `NONE` 或 `READY` 时，渲染 `<PaperOverviewPanel paperId={resumeId} />`。
  - 否则渲染占位提示「切题完成后可预览」，不发请求。

### A3 状态与分支

| 条件 | 前端表现 | 后端表现 |
| --- | --- | --- |
| `analysisStatus=COMPLETED` 且 `recognitionStatus in {NONE, READY}` | 渲染 `PaperOverviewPanel`，请求接口 | 读取缓存结构并返回 |
| `analysisStatus in {PENDING, PROCESSING, FAILED}` | 占位「切题完成后可预览」 | 不请求；若被请求返回 BAD_REQUEST |
| `recognitionStatus in {PENDING, PROCESSING, NEEDS_REVIEW, EXTRACTING, FAILED}` | 占位「切题完成后可预览」 | 不请求；若被请求返回 BAD_REQUEST |
| 结构缓存缺失 | 显示加载失败文案「试卷结构缓存缺失，请重新切题后再查看」 | 返回 BAD_REQUEST，不调用模型 |
| 无权限 / 不存在 | 接口 404，显示加载失败占位 | `NOT_FOUND` |
| 结构无题目 | 显示「暂无题目」 | 返回空 `paperTree` |
