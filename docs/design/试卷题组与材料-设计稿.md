# 试卷「材料 + 题组」结构 · 设计稿

> 状态：数据模型部分已被 `试卷层级树-设计稿.md` 取代（升级为任意层级树）；切题两段式、批改带材料、兼容策略仍然有效。
> 关联问题：高三语文模拟卷这类「阅读材料 + 若干小题」的试卷，切题后只能得到平铺的 23 道题，子题无法归类到所属材料（题组）下。

---

## 一、现状与根因

### 1.1 实测证据

上传《高三语文模拟试卷.txt》（134 行、23 题、150 分）后：

| 检查项 | 结果 |
| --- | --- |
| 题量 / 卷面总分 | 23 题 / 150 分 ✓ |
| 题型判定 | 单选、简答、填空、写作均正确 ✓ |
| **材料正文** | **丢失**：第 1 题题干只有 200 字（题干 + 4 个选项），材料一、材料二各数百字没有任何落点 |
| 题组分关系 | 不存在，23 道题平铺 |

### 1.2 根因

试卷的真实结构是三层，而当前数据模型只有一层：

```
试卷 → 大题/板块（一、现代文阅读）→ 题组（材料 + 若干小题）→ 小题
                                     ↑ 这一层缺失
```

具体到代码：

1. 切题输出结构 `ExtractedQuestion` 只有题干、选项、分值、知识点、参考答案，**没有材料字段**；
2. Prompt 又明确要求「题干只放题目本身，不要把选项正文重复写进题干」，于是材料在模型这一侧被直接丢弃；
3. 落库只存题目数组，前端只能平铺渲染。

### 1.3 连带影响

| 影响面 | 具体表现 |
| --- | --- |
| 作答 | 阅读题看不到材料，学生无法作答 |
| 批改 | 主观题批改时模型看不到材料，只能凭参考答案判断，无法评价「是否结合文本」 |
| 统计 | 只能统计到知识板块，做不出「现代文阅读 12/17 分」这类大题维度 |
| 复习 | 无法按材料组织复习（同一材料下 3 题全错，本应一起回看） |

---

## 二、目标

1. **分层建模**：题组（材料 + 所属小题）成为一等公民，小题挂到题组上；
2. **材料只存一份**：材料原文独立存储，不复写进每题题干；
3. **界面按题组组织**：组头 + 可折叠材料 + 组内小题，答题卡按题组分段；
4. **批改带上下文**：主观题批改时把该题所属材料一并送入模型；
5. **统计到题组**：组内折算分求和 / 组内满分，作为知识板块之外的第二个维度；
6. **老数据零迁移**：没有题组信息的会话仍按单题平铺渲染。

## 三、数据模型（推荐方案：新增一列 + 题目挂 groupId）

### 3.1 存储

`practice_sessions` 新增一列 `materials_json TEXT`，存题组与材料：

```json
[
  {
    "id": "G1",
    "title": "一、现代文阅读",
    "subTitle": "（一）现代文阅读 I（本题共 5 小题，19 分）",
    "materialText": "材料一：……\n\n材料二：……",
    "questionIndexes": [0, 1, 2, 3, 4],
    "fullScore": 19
  }
]
```

题目侧（`questions_json` 里的每题）新增两个可选字段：

| 字段 | 说明 |
| --- | --- |
| `groupId` | 所属题组，如 `"G1"`；无材料的独立题可为空 |
| `materialId` | 预留：一道题引用多材料时使用（本轮先不实现） |

### 3.2 为什么不让 `questions_json` 变成对象

把 `questions_json` 改成 `{questions:[], groups:[]}` 更内聚，但所有读取点（缓存、批改、报告、前端）都要做新旧格式兼容，风险高于收益。新增一列为空时即可判定为老数据，兼容逻辑只有一处。

### 3.3 备选方案（长期演进）

把题目从 JSON 提升为 `practice_questions` 行表、材料独立成 `practice_materials` 表，支持材料复用与 SQL 统计。等做「知识点标签落表 + 错题本」时一起做更划算，本轮不建议。

## 四、切题链路如何产出分组

### 4.1 调整切题流程：先识别结构，再按题组切题

现有流程是「按题号预切块 → 分批送模型」，材料只存在于第一批的上下文里，模型无法把它落到任何字段。建议改为两段式：

```
① 结构识别（一次调用或纯规则）
   输入：整卷文本
   输出：题组骨架 [{title, subTitle, materialText, questionNos:[1..5]}, ...]
         + 无材料题目区间
② 按题组切题（每组一次调用，材料作为该组上下文）
   输入：该组材料 + 该组题号区间的原文
   输出：该组的小题（题干/选项/答案/知识点/分值）+ groupId
```

好处：

- 材料有明确落点，不会丢；
- 一个题组 3～5 题，正好一批一组，「阅读题跨批导致材料被截断」的问题自然消失；
- 结构识别的结果可以复用于界面（组标题、大题分值）与统计。

### 4.2 Prompt 输出结构

```json
{
  "subjectKey": "chinese",
  "groups": [
    {
      "groupNo": 1,
      "title": "一、现代文阅读",
      "subTitle": "（一）现代文阅读 I（本题共 5 小题，19 分）",
      "materialText": "材料一：……\n\n材料二：……",
      "questionNos": [1, 2, 3, 4, 5]
    }
  ],
  "questions": [
    { "questionNo": 1, "groupId": 1, "questionType": "SINGLE_CHOICE", "question": "……", "options": ["A. …"] }
  ]
}
```

规则要点：

1. `materialText` 只输出一次，**不得复制进任何题干**；
2. 题号区间以材料后的「完成 1～5 题」为准；没有该提示时按下一则材料/大题标题为界；
3. 无材料的题（语言文字运用、名句默写）可以独立成组，`materialText` 为空；
4. 材料里的「材料一 / 材料二」等小标题保留在 `materialText` 内，界面原样展示。

### 4.3 后端兜底（规则 + 校验）

模型识别失败时用正则兜底，并写解析告警：

| 规则 | 作用 |
| --- | --- |
| 行首「一、」「二、」等中文序号 | 大题边界 |
| 行首「（一）」「1.」+ 含「阅读」「材料」 | 题组边界 |
| 「阅读下面的文字，完成 X～Y 题」 | 最可靠的题号区间线索 |
| 空行 + 连续长度 > 120 字且不含选项标签 | 材料块特征 |
| 校验 | 每题必须归属唯一题组；组内题号连续；组内分值之和 = 组满分（对不上写告警） |

## 五、前端渲染

### 5.1 题组卡片

```
┌ 一、现代文阅读 · 本题共 5 小题 19 分        [收起材料] [固定材料] ┐
│ 材料一：中华文明源远流长……                                        │
│ 材料二：考古学是通过实物遗存研究过去人类社会的学科……              │
├──────────────────────────────────────────────────────────────────┤
│ 1.（单选 3 分）下列对材料相关内容的理解和分析，正确的一项是         │
│    A/B/C/D 可点选                                                │
│ 2.（单选 3 分）……                                                │
│ 4.（简答 4 分）材料二使用了哪些论证方法？请简要说明。               │
└──────────────────────────────────────────────────────────────────┘
```

- 材料区默认展开、可折叠；「固定材料」用于 P1 的悬浮/粘性查看；
- 组头显示组满分与组内进度（已答 2/5）；
- 无材料题组退化为普通卡片（与现状一致）。

### 5.2 答题卡

按题组分段显示，组间留空隙；点击题号跳到对应小题，点击组标题跳到组头。

## 六、批改

| 题型 | 调整 |
| --- | --- |
| 客观题 | 不变（确定性判分） |
| 主观题 | 把该题所属题组的 `materialText` 作为上下文一并送入模型，评语要求「指出是否结合材料、要点是否齐全」 |
| 统计 | 新增题组维度：组内折算分之和 / 组满分 |

实现落点：`QaRecord` 增加 `contextText` 字段（或复用现有 `referenceContext` 拼接材料），`AnswerEvaluationService` 组装时按 `groupId` 取材料。

## 七、兼容与迁移

| 场景 | 处理 |
| --- | --- |
| 老会话（无 `materials_json`） | 题目按「每题一组」平铺渲染，行为不变 |
| 老试卷（材料已丢失） | 点「重新切题」用新链路重跑即可补齐材料 |
| 数据库 | 新增一列；沿用上次的 Flyway `repair` + 补列方式，或直接重建开发库 |

## 十、验收标准

1. 上传这份 23 题的语文模拟卷后，材料一、材料二正文完整出现在题组内，且只出现一次；
2. 题号 1～5 归属「现代文阅读 I」题组，6～9 归属「现代文阅读 II」，依此类推；
3. 作答页能边看材料边答题，答题卡按题组分段；
4. 主观题批改的评语能指出「是否结合材料」；
5. 报告页给出题组维度得分；
6. 老会话（无题组数据）仍能正常打开与批改。
