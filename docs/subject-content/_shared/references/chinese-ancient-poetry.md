# 古诗文阅读

## 一、文言文阅读

### 高频考点
- **实词**：一词多义、古今异义、通假字、词类活用（名作动、名作状、形作名、使动、意动）。
- **虚词**：而、以、于、之、其、乃、则、且、若、为、与、因、所、者、也。重点区分"之"（结构助词/取消句子独立性/音节助词/代词）、"以"（介词/连词/动词）、"而"（并列/承接/转折/修饰）。
- **特殊句式**：判断句、被动句、宾语前置、状语后置、定语后置、省略句、固定句式（"所以""何以""孰与""无乃……乎"）。
- **断句**：先抓名词代词定主宾，再看对话标志（曰、云、言）与句式对称，最后验语义。
- **文化常识**：科举（乡试、会试、殿试；秀才、举人、贡士、进士）、官职任免（除、拜、迁、左迁、黜、摄、判）、宗法制度、历法纪年、礼俗称谓。

### 翻译题评分
- 采分点落在关键词（实词、虚词、活用）与特殊句式上，"字字落实，直译为主，意译为辅"。
- 常见失分：漏译关键词、句式未调整、专有名词硬译。

## 二、古诗词鉴赏

### 四步读诗
读题目 -> 读作者与注释 -> 读意象 -> 读情感关键词。

### 核心考点
- **形象**：人物形象、景物形象、事物形象。
- **意象与意境**：常见意象（月、柳、雁、酒、舟、梧桐、杜鹃、流水、落日）的情感指向；意境用"雄浑壮阔、萧瑟凄凉、恬静优美、清新明丽"等术语概括。
- **表达技巧**：修辞（比喻、拟人、夸张、借代、双关、用典、对比）、表现手法（衬托、虚实结合、动静结合、视听结合、正侧结合、借景抒情、托物言志、欲扬先抑）、结构技巧（起承转合、以景结情、首尾呼应）。
- **思想感情**：忧国伤时、建功报国、思乡怀人、离愁别绪、闲适隐逸、怀古咏史、人生感慨。
- **比较鉴赏**：同题异构、同人异期、同象异情，答题必须先"求同"再"辨异"，逐条对应。

### 答题规范
手法 + 诗句具体内容 + 表达效果 + 情感。四要素缺一扣分。
