# 语言文字运用

## 一、成语与词语
- 高频误用类型：望文生义、褒贬误用、对象误用、重复赘余、自相矛盾、谦敬错位、搭配不当。
- 辨析近义成语：从语义轻重、范围大小、感情色彩、适用对象、语法功能五个维度切入。
- 虚词与关联词：辨析递进、转折、因果、条件、并列关系，注意关联词与主语的位置关系。

## 二、病句辨析

结构类：
- 语序不当（多层定语、多层状语、关联词位置、主客体倒置）
- 搭配不当（主谓、动宾、主宾、修饰语与中心语、一面对两面）
- 成分残缺或赘余（缺主语、缺谓语、缺宾语、介词滥用导致主语残缺）
- 结构混乱（句式杂糅、中途易辙、反客为主）

语义类：
- 表意不明（指代不明、停顿歧义、词义两可）
- 不合逻辑（自相矛盾、范围不清、否定失当、强加因果、主客颠倒）

## 三、标点符号
- 顿号与逗号、分号与逗号的层级关系；并列成分内部已有顿号时用逗号。
- 引号与点号的位置：完整引用时点号在引号内，非完整引用时点号在引号外。
- 冒号的提示范围，破折号的解释、转折、递进用法，省略号的"等等"与语意未尽。
- 书名号只用于书名、篇名、报刊名，不用于活动名称。

## 四、衔接连贯与语句补写
- **语句复位**：抓话题一致、句式一致、语境一致、逻辑一致、照应与指代。
- **补写句子**：定位空缺处与上下文的逻辑关系（总分、转折、因果、并列），补写后回读验证主语一致与标点匹配。
- **压缩语段**：保留主体、核心事件、结果，删除修饰与举例，注意字数限制。

## 五、修辞与表达效果
- 比喻、比拟、借代、夸张、对偶、排比、反复、反问、设问、双关、通感、互文。
- 新高考常见问法："文中画横线句使用了什么修辞？请结合内容分析其表达效果。"
- 答题结构：指明修辞 -> 还原本体喻体/具体表现 -> 效果（生动形象、突出强调、增强气势、引人深思）-> 情感。

## 六、语言得体与逻辑推断
- 谦敬辞：家父、舍弟、愚见、拙作为谦辞；令尊、贤弟、高见、大作、惠存为敬辞。
- 场合用语：书面语与口语、正式与非正式的表达差异。
- 逻辑推断：条件关系误用、充分必要混淆、偷换论题、以偏概全、循环论证。
