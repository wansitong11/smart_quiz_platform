# 完形填空

## 一、考查本质
完形填空考查的是**语篇理解 + 词汇辨析 + 逻辑衔接**的综合能力，不是孤立语法。
首句通常不设空，是全文的"窗口句"，需先读懂它确定话题、人物、时间与基调。

## 二、解题步骤
1. 跳过空格通读全文，抓住主旨、人物关系、事件走向与情感基调。
2. 逐句细读，先做有把握的题，缩小后续选项范围。
3. 对每个空判断"考什么"：词义辨析、逻辑关系、固定搭配、语法形式、上下文复现。
4. 复查：把所选词代入通读，检查语义连贯、语法正确、时态一致。

## 三、四大线索

### 1. 语义线索
上下文对空格的解释、定义、举例、比较关系。

### 2. 逻辑线索
- 转折：but、however、yet、instead、on the contrary
- 因果：because、so、therefore、thus、as a result、consequently
- 递进：moreover、furthermore、besides、what's more、in addition
- 让步：although、though、even though、despite、in spite of
- 并列：and、or、as well as、meanwhile
**判断逻辑走向是完形的第一大得分点。**

### 3. 词汇线索
- 复现：原词复现、同义词复现、反义词复现、上下义词复现。
- 搭配：动词 + 介词、形容词 + 介词、名词 + 介词。
- 同现：同一话题下常一起出现的词群。

### 4. 语法线索
时态、语态、非谓语、主谓一致、代词指代、连词与从句结构。

## 四、高频考点分布
- **动词**：占比最高。辨析动作的准确性与方向性（如表示"看"的动词、"说"的动词、"得到/失去"的动词）。
- **名词**：具体与抽象、单复数、可数与不可数。
- **形容词与副词**：情感色彩（positive / negative）、程度强弱、修饰对象。
- **连词与副词**：逻辑关系，是提分关键。

## 五、常见失分原因
- 未通读全文就逐空硬做，导致局部正确、整体矛盾。
- 只看搭配不看语境，选了语法正确但语义不通的词。
- 忽略情感基调，把褒义词填入贬义语境。
- 忽略首句与尾句的点题作用。
- 时间分配失衡，最后几空草率作答。

## 六、训练建议
- 每次做完统计错因分类（词汇 40% / 逻辑 35% / 语法 25% 为典型分布），针对性补弱。
- 精读错题原文，标注每个空的线索来源，形成"线索意识"。
