# 语法与语法填空

## 一、动词时态与语态
- 一般现在时（客观真理、习惯）、一般过去时（过去具体时间）、一般将来时（will / be going to 区别）。
- 现在完成时（对现在的影响、for/since 延续）vs 一般过去时（与具体过去时间连用）。
- 过去完成时（"过去的过去"）、现在完成进行时（持续并仍在延续）。
- 被动语态：各时态的被动形式；不用被动的常见情形（happen、belong to、consist of、break out 等不及物动词）。
- **主谓一致**：就近原则（either...or、neither...nor、there be）、就远原则（as well as、with、together with）、集合名词谓语的单复数选择。

## 二、非谓语动词
- **不定式**：表目的、结果、将来；接不定式的常见动词（decide, hope, manage, fail, afford, refuse）。
- **动名词**：作主语、宾语、介词宾语；接动名词的常见动词（enjoy, avoid, mind, suggest, look forward to, be used to）。
- **现在分词**：主动、进行；作状语表时间、原因、条件、伴随、结果。
- **过去分词**：被动、完成；作定语、状语、补语。
- **独立主格**：逻辑主语与句子主语不一致时自带主语。
- **独立成分**：generally speaking、judging from、to be honest 等固定形式。
- 判断步骤：先看句子是否已有谓语 -> 确定用非谓语 -> 找逻辑主语 -> 判断主动或被动。

## 三、定语从句
- 关系代词：who、whom、whose、which、that（指物 / 指人、先行词为不定代词或有序数词最高级修饰时用 that）。
- 关系副词：when（时间）、where（地点）、why（原因）= 介词 + which。
- 限制性与非限制性：非限制性不用 that，不能用逗号分隔后省略。
- 介词 + 关系代词：介词的选择取决于从句中的搭配。
- **易错**：way 作先行词时关系词用 in which / that 或省略；the reason why / for which。

## 四、名词性从句
- 主语从句、宾语从句、表语从句、同位语从句。
- 连接词选择：that（不做成分、无意义）、whether / if（是否）、连接代词 what / who / which / whose、连接副词 when / where / why / how。
- 语序一律用陈述语序。
- 同位语从句与定语从句的区别：同位语从句解释内容，that 不做成分。
- it 作形式主语 / 形式宾语的结构。

## 五、状语从句
- 时间：when、while、as、before、after、until / till、as soon as、the moment。
- 条件：if、unless、as long as、in case、provided that。
- 让步：although / though、even if / even though、no matter how、however + 形容词 / 副词。
- 原因：because、since、as、now that。
- 结果与目的：so...that、such...that、so that、in order that。
- **易错**：主将从现（主句将来时，时间与条件状语从句用一般现在时）；though 与 but 不同现。

## 六、虚拟语气
- 与现在、过去、将来事实相反的三类条件句形式。
- 混合虚拟：主句与从句时间不一致时分别处理。
- wish / if only 后接从句；would rather 后接从句。
- 建议、要求、命令类动词（suggest, advise, demand, require, insist）后接 (should) + 动词原形；对应名词性从句与 It is necessary that 结构。
- 倒装虚拟：Were I you...；Had I known...；Should it rain...

## 七、情态动词与推测
- must / can / may / might / could 表推测的肯定程度，注意否定式（can't 表"不可能"，mustn't 表"禁止"）。
- must have done、can't have done、should have done、needn't have done 的语义区别。
- 情态动词 + have done 表示对过去的推测或遗憾。

## 八、特殊句式
- **倒装**：部分倒装（否定词置首、only + 状语置首、so / neither 表同样）、完全倒装（there be、here / there 置首、地点状语置首）。
- **强调句**：It is / was ... that ...；判断方法（去掉结构后句子仍完整）；not until 的强调句。
- **省略**：状语从句中的省略（主语与主句一致且含 be）；并列句中的重复成分省略。
- 独立成分与固定搭配。

## 九、语法填空解题步骤
1. 通读全文把握时态基调与语篇逻辑。
2. 判断设空类型：有提示词（词形变化）或无提示词（填功能词）。
3. 有提示词：判断词性转换、非谓语、时态语态、比较级最高级、复数。
4. 无提示词：优先考虑冠词、介词、代词、连词、关系词。
5. 回读验证语法与语义是否同时成立。
