# 阅读理解

## 一、常见文体与结构
- **应用文**：通知、广告、指南、活动介绍。特征是信息密集、结构清晰，多为细节定位题，答案按小标题分区查找。
- **记叙文**：人物 + 事件 + 情感变化。重点抓时间线、转折点与人物心理。
- **说明文**：现象 + 原因 + 影响 + 措施。重点抓主题句与逻辑关系。
- **议论文**：论点 + 论据 + 结论。重点抓作者态度与论证方式。

## 二、六大题型解法

### 1. 细节理解题
定位关键词 -> 回原文找同义替换 -> 比对选项。
设错方式：偷换概念、张冠李戴、以偏概全、无中生有、曲解原意。

### 2. 推理判断题
答案必须基于原文推理，不能凭常识或主观印象。
常见问法：infer、suggest、imply、conclude。
**原则：推理一步到位，不做二次跳跃。**

### 3. 词义猜测题
线索来源：定义解释（that is、means、refers to）、举例（such as、for example）、对比（but、unlike、instead）、因果（because、so）、构词法（词根词缀）、上下文复现。

### 4. 主旨大意题
寻找主题句（多在首段末句或各段首句）；排除范围过大、过小或以偏概全的选项。
常见问法：main idea、best title、purpose of the passage。

### 5. 作者态度题
态度词分三类：正面（approval、supportive、optimistic）、负面（critical、doubtful、disapproving）、客观（objective、neutral、informative）。
**注意区分作者态度与文中人物态度。**

### 6. 七选五（阅读填空）
- 先看选项，标注每句的"话题词 + 逻辑词 + 代词"。
- 再读文章，关注空格前后的逻辑关系与指代衔接。
- 常见线索：代词指代（it、they、this、such）、逻辑连接词、词汇复现、句式一致。
- 排除法：先做特征明显的空（有代词、有转折连词），缩小范围。
- 做完后通读验证，检查是否有选项重复或逻辑断裂。

## 三、提分关键
- **同义替换意识**：正确选项几乎都是原文的同义改写，而非原词照抄。
- **定位能力**：题干关键词 -> 原文精确位置，避免凭印象作答。
- **长难句拆解**：找主干（主谓宾），识别定语从句、状语从句、插入语、同位语。
- 时间分配：单篇不超过 7 分钟，先易后难。

## 四、常见陷阱
- 选项中出现原文原词反而可能是陷阱（局部正确、整体错误）。
- 绝对化表述（all、never、only、must）通常是错误选项。
- 因果倒置：原文 A 导致 B，选项写成 B 导致 A。
- 时态与情态偏移：原文 may，选项写成 will。
