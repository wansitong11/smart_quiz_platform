# 集合、不等式与向量

## 一、集合与常用逻辑用语
- 集合表示：列举法、描述法；元素三性（确定性、互异性、无序性）。
- 集合关系与运算：子集、真子集、交集、并集、补集；空集是任何集合的子集。
- 子集个数公式：n 元集合的子集数为 2^n，真子集数为 2^n − 1。
- 充分条件、必要条件、充要条件的判定：小范围推大范围。
- 全称量词与存在量词的否定：改量词、否结论。
- **易错**：忽略空集讨论；不等式解集端点是否含等号；集合运算中元素类型不一致（点集与数集）。

## 二、不等式
- 一元二次不等式：结合二次函数图象与判别式，注意开口方向。
- 分式不等式：移项通分，化为整式不等式，注意分母不为零。
- 绝对值不等式：|ax + b| ≤ c 型、含两个绝对值型（分类讨论或几何意义）。
- 基本不等式：a + b ≥ 2√(ab)（a, b > 0），取等条件 a = b。
  - 常用变形：a + 1/a ≥ 2；ab ≤ ((a+b)/2)²。
  - **使用前提**："一正二定三相等"，缺一不可。
- 恒成立问题：分离参数法、构造函数求最值、判别式法，注意区间端点的开闭。
- 线性规划：画可行域，平移目标函数直线，求截距最值。

## 三、平面向量
- 向量的线性运算：加法（平行四边形、三角形法则）、减法、数乘。
- 共线定理：a ∥ b ⟺ 存在唯一实数 λ 使 a = λb（b ≠ 0）；坐标形式 x₁y₂ − x₂y₁ = 0。
- 平面向量基本定理：任意向量可用两个不共线向量线性表示，系数和为 1 时终点共线。
- 数量积：a·b = |a||b|cosθ = x₁x₂ + y₁y₂。
  - 垂直：a·b = 0；夹角公式；投影向量。
- 坐标运算技巧：建系法把几何问题代数化，注意选取合适原点。

## 四、复数
- 代数形式 z = a + bi，共轭复数、模 |z| = √(a² + b²)。
- 四则运算规则，i² = −1，周期性 i^(4k+r)。
- 复平面：点 (a, b) 与向量一一对应；|z − z₀| 的几何意义是距离。
- 实系数一元二次方程在判别式小于零时的共轭虚根。
