# 函数与导数

## 一、函数基础
- 三要素：定义域、值域、对应关系；**定义域优先原则**。
- 单调性：定义法（取值、作差、变形、定号）与导数法。
- 奇偶性：定义域必须关于原点对称；f(−x) = −f(x) 为奇函数，f(−x) = f(x) 为偶函数。
- 周期性：f(x + T) = f(x)；常见变形 f(x + a) = −f(x) ⟹ 周期 2a。
- 对称性：f(a + x) = f(a − x) ⟹ 关于 x = a 对称。
- 图象变换：平移（左加右减、上加下减）、伸缩、对称、翻折（|f(x)|、f(|x|)）。

## 二、基本初等函数

### 指数与对数函数
- 运算性质：a^m·a^n = a^(m+n)；(a^m)^n = a^(mn)；log_a(MN) = log_a M + log_a N；换底公式。
- 单调性由底数决定：a > 1 递增，0 < a < 1 递减。
- 比较大小：同底用单调性，同真数用图象，底数指数都不同时借助中间量 0 或 1。
- **易错**：忽略真数大于零；忽略底数范围讨论。

### 幂函数与分段函数
- 幂函数图象随指数变化规律，注意过定点 (1, 1)。
- 分段函数求值注意代入区间；分段函数单调性要求各段单调且在分界点满足大小关系。

## 三、函数与方程
- 零点存在定理：连续函数在区间端点异号，则区间内至少一个零点。
- 零点个数问题：转化为两函数图象交点个数，数形结合。
- 常用超越不等式：e^x ≥ x + 1，ln x ≤ x − 1（x > 0），取等条件 x = 0、x = 1。

## 四、导数及其应用
- 导数定义与几何意义：切线斜率 k = f′(x₀)。
- 求导公式：幂、指数、对数、三角函数的导数；四则运算、复合函数链式法则。
- **单调性**：f′(x) > 0 则递增（注意是在区间上恒成立，非某点）。
- **极值**：f′(x₀) = 0 只是必要条件，需判断两侧导数符号变化。
- **最值**：闭区间上比较极值与端点值。
- **含参讨论**：按判别式、根的大小关系、根与区间的位置关系分类。
- **恒成立与存在性**：
  - ∀x，f(x) ≥ a ⟺ f(x)_min ≥ a
  - ∃x，f(x) ≥ a ⟺ f(x)_max ≥ a
  - 分离参数是最常用手段。
- **不等式证明**：构造函数法、最值法、放缩法（切线放缩、常用不等式放缩）。
- **双变量问题**：转化为极值点偏移或对称构造函数处理。
