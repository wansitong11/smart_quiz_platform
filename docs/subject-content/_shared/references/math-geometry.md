# 立体几何与解析几何

## 一、立体几何

### 空间点线面位置关系
- 四个公理与推论（确定平面的条件）。
- 异面直线的判定与所成角（平移法，范围 (0°, 90°]）。
- 线面平行判定与性质；面面平行判定与性质。
- 线面垂直判定与性质；面面垂直判定与性质。
- 线面角（范围 [0°, 90°]）、二面角（范围 [0°, 180°]，需按题意判断锐钝）。

### 空间向量法
- 建系前提：存在两两垂直的三条直线；否则用"斜坐标系"或改用综合法。
- 求法向量：设 n = (x, y, z)，由 n·a = 0 与 n·b = 0 联立，取一组解。
- 线面角公式：sin θ = |a·n| / (|a||n|)。
- 二面角公式：cos θ = (n₁·n₂)/(|n₁||n₂|)，**注意判断二面角是锐角还是钝角**（观察法或代入点验证）。
- 点到平面距离：d = |AP·n| / |n|。
- **易错**：法向量方向导致二面角取反；建系后点的坐标写错。

### 表面积与体积
- 柱、锥、台、球的体积与表面积公式；球的组合体问题（内切球、外接球）。
- 外接球常用方法：补形为长方体（三条棱两两垂直）、构造直角三角形利用球心性质。
- 截面问题：作截面的基本方法（平行线法、延长线找交点法）。

## 二、解析几何

### 直线与圆
- 直线方程五种形式，斜率是否存在需分类讨论。
- 两直线平行（A₁B₂ − A₂B₁ = 0）与垂直（A₁A₂ + B₁B₂ = 0）。
- 距离公式：两点间距离、点到直线距离、两平行线间距离。
- 圆的标准方程 (x−a)² + (y−b)² = r² 与一般方程 x² + y² + Dx + Ey + F = 0（D² + E² − 4F > 0）。
- 直线与圆位置关系：几何法（比较 d 与 r）优于代数法。
- 弦长公式：l = 2√(r² − d²)；切线方程与切点弦方程。
- 圆与圆位置关系：比较 |d| 与 |r₁ − r₂|、r₁ + r₂。

### 圆锥曲线
- 椭圆：x²/a² + y²/b² = 1（a > b > 0），c² = a² − b²，离心率 e = c/a ∈ (0, 1)。
- 双曲线：x²/a² − y²/b² = 1，c² = a² + b²，e = c/a ∈ (1, +∞)；渐近线 y = ±(b/a)x。
- 抛物线：y² = 2px，焦点 (p/2, 0)，准线 x = −p/2；焦半径公式。
- 通径、焦点弦、中点弦（点差法）。

### 常见题型方法
- **弦长问题**：联立方程 -> 韦达定理 -> 弦长公式 l = √(1 + k²)·|x₁ − x₂|。
- **中点弦**：点差法（设两点坐标相减），注意验证判别式大于零。
- **面积问题**：底 × 高化简，或分割为两个三角形求和。
- **定点定值问题**：设直线方程（推荐设为 x = my + t 以避免讨论斜率不存在），验证结果与参数无关。
- **最值范围问题**：转化为函数最值或利用基本不等式，注意取值范围与判别式约束。
- **易错**：联立后忘记判别式；斜率不存在情形漏讨论；结果未回代验证。
