# 数列

## 一、基本概念与通项
- 数列是定义域为正整数集的函数；通项公式 aₙ 与前 n 项和 Sₙ 的关系：aₙ = S₁ (n = 1)，aₙ = Sₙ − Sₙ₋₁ (n ≥ 2)。
- **易错**：由 Sₙ 求 aₙ 时忘记验证 n = 1 是否满足。

## 二、等差数列
- 定义：aₙ₊₁ − aₙ = d（常数）。
- 通项：aₙ = a₁ + (n − 1)d。
- 前 n 项和：Sₙ = n(a₁ + aₙ)/2 = na₁ + n(n − 1)d/2。
- 性质：
  - m + n = p + q ⟹ aₘ + aₙ = aₚ + a_q。
  - Sₙ, S₂ₙ − Sₙ, S₃ₙ − S₂ₙ 成等差数列。
  - 判断方法：定义法、中项法（2aₙ₊₁ = aₙ + aₙ₊₂）、通项为一次函数、Sₙ 为无常数项的二次函数。

## 三、等比数列
- 定义：aₙ₊₁ / aₙ = q（q ≠ 0）。
- 通项：aₙ = a₁q^(n−1)。
- 前 n 项和：q = 1 时 Sₙ = na₁；q ≠ 1 时 Sₙ = a₁(1 − q^n)/(1 − q)。
- 性质：m + n = p + q ⟹ aₘ·aₙ = aₚ·a_q；Sₙ, S₂ₙ − Sₙ, S₃ₙ − S₂ₙ 成等比（公比不为 −1 或 n 为偶数时需单独验证）。
- **易错**：忽略 q = 1 的情形；忽略 q ≠ 0。

## 四、求通项的方法
- 公式法、累加法（aₙ₊₁ − aₙ = f(n)）、累乘法（aₙ₊₁/aₙ = f(n)）。
- 构造法：aₙ₊₁ = paₙ + q 型构造等比数列（配凑 aₙ₊₁ + λ = p(aₙ + λ)）。
- 取倒数法：适用于分式递推 aₙ₊₁ = aₙ/(paₙ + q)。
- 由 Sₙ 与 aₙ 混合关系求通项：两式相减消 Sₙ。

## 五、求和方法
- 公式法、分组求和、错位相减（等差 × 等比型）、裂项相消（1/(n(n+k)) 型）、倒序相加、并项求和。
- **错位相减易错**：相减后项数错误、首末项遗漏、公比为字母时未讨论。
- **裂项相消易错**：裂项系数漏写、剩余项未数对。

## 六、数列不等式与综合
- 放缩证明：把通项放缩为可求和形式（如 1/n² < 1/(n(n−1))）。
- 数列单调性与最值：作差或作商判断；Sₙ 最值看项的符号变化点。
- 数列与函数、导数的综合：构造新数列或构造函数研究单调性。
