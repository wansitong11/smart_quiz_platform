# 三角函数与解三角形

## 一、任意角与弧度制
- 终边相同的角：α + k·360°（k ∈ Z）。
- 象限角与轴线角的集合表示。
- 弧长 l = |α|r，扇形面积 S = ½lr = ½|α|r²。
- 角度与弧度互化：180° = π。

## 二、三角函数定义与基本关系
- 单位圆定义：(cos α, sin α)，tan α = sin α / cos α。
- 同角关系：sin²α + cos²α = 1；tan α = sin α / cos α。
- 诱导公式口诀：奇变偶不变，符号看象限。
- 三角函数线及其应用（比较大小、解不等式）。

## 三、图象与性质

对 y = A sin(ωx + φ) + B：
- 振幅 |A|，周期 T = 2π/|ω|，初相 φ，值域 [B − |A|, B + |A|]。
- 五点法作图；由 y = sin x 到 y = A sin(ωx + φ) 的变换顺序（先平移后伸缩与先伸缩后平移的区别）。
- 单调区间：整体代换 ωx + φ 落在标准区间内求解，注意 ω 的正负。
- 对称轴：ωx + φ = π/2 + kπ；对称中心：ωx + φ = kπ。
- **易错**：求单调区间时未说明 k ∈ Z；未考虑 ω < 0 时需先化正。

## 四、三角恒等变换
- 两角和差公式：sin(α ± β)、cos(α ± β)、tan(α ± β)。
- 二倍角公式：sin 2α = 2 sin α cos α；cos 2α = cos²α − sin²α = 2cos²α − 1 = 1 − 2sin²α；tan 2α。
- 降幂公式：cos²α = (1 + cos 2α)/2；sin²α = (1 − cos 2α)/2。
- 辅助角公式：a sin x + b cos x = √(a² + b²) sin(x + φ)，其中 tan φ = b/a。
- 常用技巧：切化弦、弦化切、1 的代换（sin²+cos²=1）、角的拆分（α = (α+β) − β）。
- 给值求值、给值求角：先确定角的范围，再定函数值的符号。

## 五、解三角形
- 正弦定理：a/sin A = b/sin B = c/sin C = 2R。
  - 适用：已知两角一边、已知两边及其中一边对角。
  - 已知两边及其中一边对角时需讨论解的个数（锐角、直角、钝角）。
- 余弦定理：a² = b² + c² − 2bc cos A，及其变形 cos A = (b² + c² − a²)/(2bc)。
  - 适用：已知三边、已知两边及夹角。
- 面积公式：S = ½ab sin C = ½ac sin B = ½bc sin A。
- 三角形内角关系：A + B + C = π，sin(A + B) = sin C，cos(A + B) = −cos C。
- 常见考法：判断三角形形状（边角互化）、求周长或面积最值（结合余弦定理与基本不等式）、多三角形组合图形（注意公共边与公共角）。
