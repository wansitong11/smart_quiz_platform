一、知识库上传注意事项

核心原则：上传前请务必确认资料版权合规，优先使用公开免费资源或自有原创资料。

1. 支持的文件格式

类型 推荐格式 说明
文档 PDF、DOCX、TXT、MD PDF需文本可选中（非扫描件）；Word建议用.docx
表格 XLSX、CSV 结构化数据更适合检索
网页 HTML UTF-8编码
电子书 EPUB 部分平台支持

2. 文件质量要求

  • 清晰度：文字清晰可识别，避免模糊扫描件或低分辨率图片
  • 命名规范：使用有意义的文件名，如 小学英语-三年级-单词表.pdf，避免 123.pdf
  • 内容完整：确保文件不残缺、页码连续
  • 编码正确：中文文档统一使用 UTF-8 编码，避免乱码
  • 去重整理：相同内容避免重复上传，建议合并同类资料

3. 内容组织建议

  • 按 学科 → 年级/难度 → 类型 建立文件夹层级
  • 每份资料附带简短说明（如适用年级、内容摘要、题型等）
  • 试卷类资料建议同时上传答案版，方便对照
  • 优先上传 纯文本可检索 的文档，图片型 PDF 检索效果较差
提示：如果资料是图片扫描件，建议先用 OCR 工具（如 Adobe Acrobat、ABBYY、WPS 等）识别为可检索文本后再上传。

资料质量检查清单

  • ☐ 文件格式是否为 PDF / DOCX / TXT / XLSX 等可检索格式
  • ☐ 扫描件是否已做 OCR 文字识别
  • ☐ 文件名是否清晰描述内容（如：2026-人教版-小学英语三年级上册-单词表）
  • ☐ 是否有配套的答案/解析（尤其试卷类）
  • ☐ 文件大小是否合理（单文件建议不超过 50MB）
  • ☐ 内容是否为最新版本（教材/考纲是否对应2024-2026年）
最后提醒：定期清理过期资料（如旧版教材、已废止考纲），保持知识库内容的新鲜度和准确性。建议每半年做一次资料审核更新。
