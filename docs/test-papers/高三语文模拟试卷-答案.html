6. C（3分）

四、写作（60分）
23. 评分标准及说明
一、审题立意
材料提供了对"青春"的多种理解：远行（逝去不可追）、相逢（美好难忘）、伤痛（遗憾惋惜），以及"伟大力量"（积极意义）。写作时需围绕"青春"展开，可以从以下角度立意：
①珍惜青春，把握当下；②青春的价值在于奋斗；③青春是一种心态；④青春的遗憾与成长；⑤青春的多元解读。

参考范文
以青春之名，赴时代之约

青春，是人生中最美好的年华，是梦想萌芽的季节，是激情燃烧的岁月。有人说青春是一场远行，一旦出发便无法回头；有人说青春是一场相逢，那些人与事将铭记一生；也有人说青春是一场伤痛，教会我们成长与坚强。而我认为，青春更是一份责任、一种担当，是以奋斗为底色的生命华章。

青春的价值在于奋斗。回望历史，无数青年以青春之我，创建青春之国家。百年前，一群平均年龄仅28岁的青年，在嘉兴南湖的一叶红船上，点燃了中国革命的星星之火。他们本可以选择安稳的人生，却毅然决然地踏上了救亡图存的道路。正是这份青春的热血与担当，改变了中国的命运。今天，新时代的青年同样在用奋斗诠释青春——航天报国的嫦娥团队、北斗团队平均年龄仅30多岁；抗疫一线的医护人员中，"90后""00后"成为主力军。他们用行动证明：青春因奋斗而精彩，人生因担当而厚重。

青春的意义在于成长。青春不仅有诗和远方，也有迷茫与挫折。正是那些伤痛与遗憾，让我们学会了坚强与成熟。史铁生在最好的年华里失去了行走的能力，却在轮椅上写出了震撼人心的文字；贝多芬在青春时期便开始耳聋，却谱写出了《命运交响曲》这样不朽的乐章。青春的伤痛不是终点，而是蜕变的起点。每一次跌倒后的爬起，每一回失败后的坚持，都在为生命的厚度添砖加瓦。

青春的底色在于家国。个人的青春只有融入时代的洪流，才能绽放出最耀眼的光芒。钱学森放弃美国的优渥条件，毅然回国投身航天事业，用青春和智慧铸就了大国重器；黄文秀北师大硕士毕业后，主动回到家乡担任驻村第一书记，将青春奉献给了脱贫攻坚事业。他们用青春诠释了什么是"苟利国家生死以，岂因祸福避趋之"。当代青年生逢盛世，更当以家国为己任，将个人理想融入民族复兴的伟大征程。

诚然，青春终将逝去，但青春的精神可以永驻。年龄的增长无法阻挡，但心态的年轻由自己决定。只要心中有梦、眼里有光、脚下有路，每一个日子都可以过得热气腾腾。正如塞缪尔·厄尔曼所言："青春不是年华，而是心境；青春不是桃面、丹唇、柔膝，而是深沉的意志、恢宏的想象、炽热的感情。"

青春是一场无法重播的电影，但我们可以在有限的时光里书写无限的精彩。以青春之名，赴时代之约，用奋斗的姿态拥抱未来，用担当的精神砥砺前行。这，才是青春最好的模样。
